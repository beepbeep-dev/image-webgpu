🧠 Diffusion mode setup (optional, experimental)

The built-in neural model works with zero setup. To instead run a larger external text-to-image model entirely in your browser via ONNX Runtime Web + WebGPU, load a small, quantized ONNX model from your device. Files never leave your machine.

  1. Download a small/quantized text-to-image ONNX model locally (e.g. a quantized SD-Turbo / Tiny-SD export). On a 3 GB device, only the smallest int8 models have a chance of fitting.
  2. Pick the model folder / .onnx files below.
  3. Press Generate with the Diffusion engine selected.

Honest caveat: this single-file app provides the WebGPU/ONNX runtime, capability checks and the generation loop scaffolding, but a full diffusion pipeline (tokenizer + text encoder + UNet scheduler loop + VAE) depends on the exact model you supply. If a model isn't loaded or doesn't fit in memory, the app falls back to the built-in neural model and tells you why.

🧬 Neural model (default): a real ~31k-parameter neural network trained from scratch (a conditional neural field) that generates scenes — sky by time of day, ground by biome, optional mountains / neon / fire, plus simple subjects like a person, horse, dog, car, bird, boat, tree or building — from your prompt. The trained weights are embedded in this file (~165 KB), so it runs fully offline with no downloads and fits the iPad-9 memory budget. ⚡ Procedural is the instant WebGPU keyword-art engine; 🧠 Diffusion is the optional bring-your-own-ONNX path.
