🧠 Diffusion mode setup (optional, experimental)

The Local engine works with zero setup. To run a real neural text-to-image model entirely in your browser via ONNX Runtime Web + WebGPU, load a small, quantized ONNX model from your device. Files never leave your machine.

  1. Download a small/quantized text-to-image ONNX model locally (e.g. a quantized SD-Turbo / Tiny-SD export). On a 3 GB device, only the smallest int8 models have a chance of fitting.
  2. Pick the model folder / .onnx files below.
  3. Press Generate with the Diffusion engine selected.

Honest caveat: this single-file app provides the WebGPU/ONNX runtime, capability checks and the generation loop scaffolding, but a full diffusion pipeline (tokenizer + text encoder + UNet scheduler loop + VAE) depends on the exact model you supply. If a model isn't loaded or doesn't fit in memory, the app falls back to the Local engine and tells you why.

How the Local engine works: your prompt's keywords pick a color palette and mood, the seed makes it reproducible, and "steps" refines detail. It's real procedural synthesis (not a neural net), so it's instant and tiny — perfect for low-RAM devices.
